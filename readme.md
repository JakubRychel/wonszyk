# Wonszyk (Snake Game)

Prosta gra w węża napisana w Pythonie. Klasyczna zabawa, gdzie sterujesz wężem, jedząc jedzenie i unikając ścian oraz własnego ogona.

## Wymagania

- Python 3.x

## Jak uruchomić

1. Upewnij się, że masz zainstalowanego Pythona.
2. Uruchom grę poleceniem:
   ```
   python main.py
   ```

## Sterowanie

- Strzałki: poruszanie wężem
- ESC: wyjście z gry

## Pliki projektu

- `main.py`: główny plik uruchamiający grę
- `settings.py`: ustawienia gry
- `game/`: moduły gry
  - `snake.py`: logika węża
  - `food.py`: logika jedzenia
  - `game.py`: główna logika gry
